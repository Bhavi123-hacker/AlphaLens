The evaluation reader checks forecast source/inference/recording/entry ordering and requires a stored outcome with five actual input sessions, official saved timing and next-session chain, later source retrieval/publication, compatible target, no action exclusion and an exact rational next-open/fifth-close calculation. It does not reconcile or append outcomes. Accuracy and frozen majority/momentum/mean-reversion comparisons use eligible matured decisions only with the existing 0.5 threshold. Balanced accuracy requires both classes; incompatible model/target groups remain separate. These are interim descriptive matured-sample metrics, **not** registered global-cohort acceptance or evidence of profit. Existing global-cohort evaluation and independent approval gates remain unchanged.
